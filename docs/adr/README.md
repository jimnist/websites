# Architecture Decision Records

Repo-wide architectural decisions live here, one file per decision
(`NNNN-short-title.md`).

The `domain-modeling` skill writes and updates these as decisions are made
during `/grill-with-docs`. Add an ADR when you make a decision that a future
agent would otherwise have to reverse-engineer or might unknowingly contradict.

Per-app domain language lives in each app's `CONTEXT.md`, indexed by the
root `CONTEXT-MAP.md` - not here.
